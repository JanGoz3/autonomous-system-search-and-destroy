# Autonomous Vehicle Edge Control System

An end-to-end, real-time autonomous driving system deployed on edge hardware (NVIDIA Jetson Nano Orin). This project bridges the gap between simulated training (Sim2Real via Unity) and physical hardware execution, utilizing a multi-threaded Python architecture for low-latency continuous control.

## Key Features
* **Edge AI Deployment:** Custom PyTorch models exported to ONNX and accelerated with TensorRT for high-performance, real-time inference directly on the hardware.
* **Multi-Threaded Architecture:** Concurrent management of a GStreamer video pipeline, UDP-based ARCore odometry, and serial hardware actuators within a strict 20Hz closed-loop control system.
* **Modular AI Pipeline:** 
  * **Perception:** YOLO-based object detection optimized to compress spatial data into a lightweight 14-value state vector.
  * **Planning:** Waypoint Transformer trained via Behavioral Cloning on synthetic data generated by a procedural expert in Unity.
  * **Control:** Proximal Policy Optimization (PPO) Actor-Critic controller.
* **Deterministic Fallback ("Search & Destroy"):** A specialized targeting mode that bypasses neural networks in favor of a robust, deterministic Proportional (P) controller for guaranteed stability.
* **Client-Server Networking:** Custom TCP/UDP socket servers to handle live video telemetry and remote gamepad overrides.

## Tech Stack
* **Languages:** Python
* **AI/ML:** PyTorch, ONNXRuntime, YOLO, Reinforcement Learning (PPO), Transformers
* **Hardware & Edge:** NVIDIA Jetson Nano Orin, TensorRT, Serial Communication
* **Simulation & Data:** Unity3D (Sim2Real pipeline)
* **Vision & Networking:** OpenCV, GStreamer, UDP/TCP Sockets

## System Architecture overview
The main system (`main.py`) acts as the central hub, continuously ingesting sensor data (camera frames, IMU/ToF buffers, odometry), passing it through the decoupled AI modules, and dispatching motor commands. To maintain the 20Hz requirement, heavy visual processing is isolated from the downstream decision-making modules.
